# Security

## Reporting a vulnerability

Write to **security@kubelatch.com**, or use this repository's private vulnerability reporting, with what you found, how to reproduce it and the version of the action. We acknowledge within 3 business days, keep you informed, and publish a fix and an advisory; we ask for 90 days of coordinated disclosure. Please do not open a public issue for a vulnerability.

The policy for kubelatch itself, and what it covers, is in [kubelatch's SECURITY.md](https://github.com/picaportelabs/kubelatch/blob/main/SECURITY.md).

## Supported versions

The latest 1.x release, which `v1` points at.
